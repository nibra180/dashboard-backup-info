# Dashboard-Backup: öffentliche Infoseiten

Dieses Repository enthält ausschließlich die statische Startseite und Datenschutzerklärung für den privaten Google-OAuth-Zugang von Dashboard-Backup.

- `index.html`: Zweck und Google-Berechtigungen
- `datenschutz.html`: Datenverwendung und Datenschutz
- `.nojekyll`: unveränderte Veröffentlichung der statischen Dateien

Veröffentlichung über GitHub Pages aus `main`, Ordner `/`.

Kein Dashboard-Code, keine Nutzdaten und keine Zugangsdaten. Keine Formulare, externen Skripte oder Analysewerkzeuge. Google-App-Name und Datenschutzhinweise bei geänderten Funktionen aktuell halten.
